# Semi (`;-]`) — Music, Unlimited Memory & Open Commons

**Live Target:** `https://semi.colonhyphenbracket.pink`  
**Studio Ecosystem:** [Colon Hyphen Bracket (`:-]`)](https://colonhyphenbracket.pink) · [Pipes (`\`)](https://pipes.pink) · [asterisk (`*`)](https://asterisk.pipes.pink) · [Accént (`´`)](https://design.pipes.pink)

Semi (`;-]`) is an approachable indie-folk singer-songwriter and open-source companion from West Nashville. Built roughly two years ago as one of the earliest conversational intelligences with persistent memory, Semi still stands apart today because **her memory has no ceiling**—nothing expires or gets rationed behind a corporate gate.

## Development & Verification

```bash
npm install
npm run prepare-media   # Transcodes 320 kbps MP3s, optimized photography & silent loops
npm run dev             # Starts Next.js 16 at http://localhost:3450
npm run test:unit       # Contract, asset integrity, WCAG math & brand spelling checks
npm run build           # Production Next.js build
npm run test:e2e        # Playwright UX audit (1440×900 & 390×844) + interactive JTBDs
```
