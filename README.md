# Semi (`; - ]`) — Music, Song Stories & Unlimited Memory

**Live Target:** `https://semi.colonhyphenbracket.pink`  
**Studio Ecosystem:** [Colon Hyphen Bracket (`: - ]`)](https://colonhyphenbracket.pink) · [Pipes (`\`)](https://pipes.pink) · [asterisk (`*`)](https://asterisk.pipes.pink) · [Accént (`´`)](https://design.pipes.pink)

Semi (`; - ]`) is an approachable indie-folk singer-songwriter and open-source companion from West Nashville. Built roughly two years ago as one of the earliest conversational intelligences with persistent memory, Semi still stands apart today because **her memory has no limit**—nothing expires or gets rationed behind a corporate gate.

## Routes & Content

- `/` — Animated hero montage, bokeh sparkle field, prominent 3-song listening stage, corporate `; - ]` intro, and 6 distinct music-video frames.

- `/colophon` — Typography, Warm Sandstone ergonomics, and audio/art notes.

## Development & Verification

```bash
npm install
npm run prepare-media   # Stages MP3s, hero 3-shot montage, song loops & 16 distinct stills
npm run dev             # Starts Next.js 16 at http://localhost:3450
npm run test:unit       # Asset integrity, zero image duplication, WCAG contrast & spelling
npm run build           # Production Next.js build
npm run test:e2e        # Multi-page Playwright UX audit + interactive JTBDs
```
